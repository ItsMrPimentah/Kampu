# Localizations

Keep user-visible strings in the project's localization resources once configured. Update all
supported locales, preserve placeholders and plural rules, and generate using Flutter's configured
`gen-l10n` workflow through Devbox. Verify generated changes and test the affected labels and
fallbacks. The current app does not yet configure localization; establish that configuration before
using the generator.
