# Project Stack

## Client Mobile Side

- **Flutter** — Mobile client framework.
- **Dio** — HTTP client.
- **freezed** — Immutable objects, value equality, serialization, and type-safe state and operation-result implementations.
- **hive_ce** — Local storage management.
- **flutter_animate** — Animations.
- **flutter_hooks** — Widget lifecycle and state management through hooks.
- **patrol** — Integration and end-to-end testing.

## Backend

- **NestJS** — Backend framework.
- **authZ** — Roles and permissions management.
- **Better Auth** — User authentication.
- **Drizzle ORM** — Type-safe database queries and data access.
- **NestJS ecosystem** — Guards, decorators, middleware, and the remaining backend infrastructure.
- **Redis** — Caching management.
- **MinIO** — Object and bucket management.

## Database

- **PostgreSQL** — Primary database management solution.
- **PostGIS** — Geospatial database extension for PostgreSQL.
